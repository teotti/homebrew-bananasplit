# BananaSplit Homebrew tap

```sh
brew install teotti/bananasplit/bananasplit
```

This installs the [BananaSplit CLI](https://github.com/teotti/banana-cli), which you can run as either `banana` or `bananasplit`.
After the first install, `brew upgrade bananasplit` keeps it up to date.

`Formula/bananasplit.rb` is generated and pushed by the CLI's release workflow, so don't edit it by hand.
